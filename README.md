# Менеджер задач (Task Manager)

Простое консольное приложение на Python для управления списком задач с сохранением данных в базе данных SQLite. 

## Требования
- Python 3.10 или выше (из-за использования синтаксиса `int | None`).
- ОС: Ubuntu (WSL2), Windows или macOS.
- Внешние библиотеки не требуются (используется только стандартная библиотека).
