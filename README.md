# Менеджер задач (Task Manager)

Простое консольное приложение для управления задачами с сохранением данных в базе SQLite. Используется только стандартная библиотека Python.

## Требования
- Python 3.10+
- ОС: Ubuntu (WSL2) или Windows/Linux

## Создание и активация виртуального окружения
*(Внешних зависимостей нет, venv опционален, но рекомендуется по заданию)*

```bash
python3 -m venv .venv
source .venv/bin/activate
